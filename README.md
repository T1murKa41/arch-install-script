# arch-install-script

Интерактивный скрипт установки Arch Linux (только UEFI).

Ставит: базовую систему, NetworkManager, rEFInd, микрокод процессора (определяется автоматически) и по желанию XFCE4 + SDDM + Firefox, zsh + oh-my-zsh.

## Запуск

Загрузитесь с Arch ISO в режиме UEFI, подключитесь к интернету и выполните:

```bash
pacman -Sy git --noconfirm
git clone https://github.com/T1murKa41/arch-install-script
cd arch-install-script
bash script.sh
```

`chroot` должен лежать рядом со `script.sh`.

## Что делает скрипт

1. Проверяет окружение: root, UEFI, сеть, нужные утилиты.
2. Показывает диски и по желанию открывает `cfdisk` для разметки.
3. Спрашивает EFI, root и swap разделы, а также нужно ли форматировать EFI (отвечайте «нет» при dual-boot).
4. Спрашивает имя пользователя, имя хоста, часовой пояс, пароли и необязательные компоненты.
5. Показывает сводку и просит ввести `YES` перед любым форматированием.
6. Устанавливает систему, настраивает её в chroot, ставит rEFInd и задаёт пароли.

## Что важно знать

- Корневой раздел всегда форматируется в ext4, все данные на нём уничтожаются.
- Пароли не передаются в аргументах командной строки и не попадают в журнал.
- Журнал установки: `/tmp/arch-install.log`.
- Скрипт не тестировался на реальном железе во всех конфигурациях — на важной машине сначала проверьте его в виртуалке (с включённым UEFI).
